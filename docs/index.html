University-1652

A multi-view, multi-source benchmark for drone-based geo-localization.

Code and documentation Paper

About the benchmark

University-1652 covers 1,652 buildings across 72 universities and supports geo-localization across drone, satellite, and street views. The dataset is available by request; see the repository README and Request.md for access instructions.
